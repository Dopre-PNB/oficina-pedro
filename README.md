# Sistema de Cadastro de Clientes da Oficina Mecânica

## Planejamento da entidade Cliente

- O veículo será identificado pela placa e pelo modelo do veículo.
- Além do e-mail, será armazenado o telefone para facilitar o contato com o cliente.
- A quilometragem atual do veículo será registrada por ser uma informação importante para os serviços e revisões da oficina.
